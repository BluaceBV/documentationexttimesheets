# Manual Extended Time Sheets
Do you want the user responsible for a project to approve the resource hours written on the project, with this extension you can set a time sheet approver on a project. 

## Key Features

* Project Manager can be set as Time Sheet Approver on the project card.
* Only the users set as project resource on the project can write their time and select the project on their time sheet card.
* The line type for time sheet lines in project journal is based on the project task line.
* Easier input of Time Sheet Lines on the Time Sheet Card.
* Setup of a temporarily project approver.
* Option to setup an unfiltered approval screen.
* Creation of **next** Time Sheet via job queue entries.
